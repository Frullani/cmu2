# Шаблон состояния игры

Используй этот формат, чтобы отслеживать и показывать состояние. Заполняй только
актуальные поля; лишние можно опускать.

## Карточка персонажа

```
🧍 Персонаж: <имя>
   Кто он: <короткое описание, роль, происхождение>
   Черта: <ключевая черта характера или навык>

❤️ Здоровье: <текущее> / <максимум>
🎒 Инвентарь: <предмет 1>, <предмет 2>, ...
💰 Ресурсы: <деньги / патроны / энергия / и т.п.>

📊 Навыки (модификаторы для проверок):
   Сила: +N   Ловкость: +N   Ум: +N   Обаяние: +N
```

## Состояние мира

```
📍 Локация: <где сейчас игрок>
🎯 Цели:
   - [ ] <активная цель>
   - [x] <выполненная цель>
🕐 Время / обстановка: <день/ночь, погода, угроза>
```

## Ключевые NPC

```
👤 <имя> — <кто такой, отношение к игроку, что известно>
```

## Журнал важных выборов

```
- <выбор игрока и его последствие>
```

---

## Формат слепка сохранения (`сохрани`)

При команде `сохрани` выведи всё состояние выше одним компактным блоком в тексте,
чтобы игрок мог его скопировать. При `загрузи <текст>` — распарсь этот блок и
продолжи игру с восстановленного момента, кратко напомнив сцену.
